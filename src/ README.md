# Employee Management System

## Project Description

This project is a Java-based Employee Management System that demonstrates Object-Oriented Programming (OOP) concepts.

The system includes three types of employees:

* **CommissionEmployee:** An employee whose salary includes a sales commission.
* **MonthlyEmployee:** An employee who receives a monthly salary and may receive a bonus.
* **HourlyEmployee:** An employee who is paid based on hours worked, including overtime.

The system also includes a Department class to manage employees, assign a department manager, display employee information, calculate individual salaries, and calculate the total department payroll.

The project uses Java classes, inheritance, constructors, methods, and an enum to represent employee gender.

## Technologies Used

* Java JDK 21
* IntelliJ IDEA
* Object-Oriented Programming (OOP)

## How to Run

1. Open the project in IntelliJ IDEA.
2. Make sure Java JDK 21 is configured.
3. Open `src/Main.java` to run the main program.
4. Click the green **Run** button next to the `main()` method.
5. The program will display employee information, individual salaries, and the total department payroll in the Run console.

### Running the Test Program

1. Open `src/test/MainTest.java`.
2. Click the green **Run** button next to the `main()` method.
3. Check the console to verify the employee information and salary calculations.
